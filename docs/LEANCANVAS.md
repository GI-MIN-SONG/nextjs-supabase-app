## 참고: 각 블록과 PRD 기능 매핑

| 캔버스 블록   | 관련 PRD 기능                                                |
| ------------- | ------------------------------------------------------------ |
| 문제          | F006, F008, F009 이 해결하는 기존 페인포인트(수동 취합/정산) |
| 솔루션        | F001, F005, F006, F007, F009, F010, F011                     |
