# 모임 이벤트 관리 웹 MVP PRD

## 🎯 핵심 정보

**목적**: 모임 주최자가 공지·참여자 관리(RSVP)·정산(N빵)을 혼자 도맡는 부담을 하나의 웹 도구로 줄여준다.
**사용자**: 수영, 헬스, 친구 모임 등을 정기적으로 운영하는 개인 모임 주최자 (참여자는 회원가입 없이 공개 링크로만 참여).

## 🚶 사용자 여정

```
[주최자 플로우]

1. 로그인 페이지 (기존 Supabase Auth)
   ↓ 로그인 성공

2. 내 모임 목록
   ↓ "새 모임 만들기" 클릭

3. 모임 생성
   ↓ 저장 완료 → 자동 이동

4. 모임 상세 (주최자)
   ↓ 참여자 공개 링크 복사하여 카톡/문자 등으로 공유
   ↓
   [참여자 현황 확인] ← 참여자 RSVP 제출 시 실시간 반영
   ↓
   [모임 정보 수정 필요] → 모임 수정 → 모임 상세로 복귀
   ↓
   [정산 필요] → 정산 계산기 → 총금액/참여자 입력 → 1인당 금액 계산 → 계좌 공유 → 입금 체크
   ↓
5. 모임 상세로 복귀 (반복 확인/정산 마감 체크)


[참여자 플로우]

1. 참여자 RSVP 랜딩 (공개 링크로 진입, 계정 불필요)
   ↓ 이름 입력 + 참석 여부 선택 + 카풀 메모(선택) 입력
   ↓ 제출

2. 제출 완료 → 개인 응답 수정 링크(access_token 포함) 안내
   ↓ 이후 같은 링크로 재방문

3. 참여자 응답 수정 페이지
   ↓ 참석 여부/메모 수정 가능
   ↓ 정산이 등록된 경우 내 분담액(1인당 금액) 확인 가능
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명                | 설명                                                              | MVP 필수 이유                                             | 관련 페이지                   |
| -------- | --------------------- | ----------------------------------------------------------------- | --------------------------------------------------------- | ----------------------------- |
| **F001** | 모임 생성             | 제목, 설명, 장소, 일시, RSVP 마감일 입력하여 모임 생성            | 모임 관리의 시작점, 없으면 서비스 자체가 불가능           | 모임 생성                     |
| **F002** | 내 모임 목록 조회     | 주최자가 만든 모임을 리스트로 확인                                | 여러 모임을 동시에 관리하는 주최자의 기본 니즈            | 내 모임 목록                  |
| **F003** | 모임 상세/공지 확인   | 모임 정보와 참여자 현황을 한 화면에서 확인                        | 주최자가 모임 운영 상태를 파악하는 핵심 화면              | 모임 상세(주최자)             |
| **F004** | 모임 정보 수정        | 생성된 모임의 제목/설명/장소/일시/마감일/상태 수정                | 일정 변경, 취소 등 현실적으로 빈번히 발생                 | 모임 수정                     |
| **F005** | 참여자 공개 링크 공유 | 로그인 없이 접근 가능한 모임별 공개 RSVP 링크 제공                | 참여자 무계정 참여라는 핵심 컨셉의 필수 수단              | 모임 상세(주최자)             |
| **F006** | 참여자 RSVP 제출      | 이름, 참석 여부, 카풀 메모(자유텍스트 1줄)를 입력해 응답 제출     | 참여자 관리의 핵심 데이터 수집 기능                       | 참여자 RSVP 랜딩              |
| **F007** | 참여자 응답 수정      | 개인 고유 링크(access_token)로 본인 응답만 재수정                 | 참석 여부 변경 등 현실적 필요, 계정 없는 구조의 핵심 장치 | 참여자 응답 수정              |
| **F008** | 참여자 현황 테이블    | 주최자가 참여자 이름/상태/메모를 표로 확인                        | 참여자 관리의 시각적 핵심, RSVP 기능의 완결               | 모임 상세(주최자)             |
| **F009** | 정산 계산(N빵)        | 총금액 입력 + 참여자별 정산 포함/제외 체크 → 1인당 금액 자동 계산 | 두 번째 우선순위 핵심 기능, 정산 부담 해소가 목적         | 정산 계산기                   |
| **F010** | 계좌 정보 공유        | 계좌번호/예금주/메모를 텍스트로 등록하여 참여자에게 안내          | 실제 결제 연동 없이 정산을 완결하는 최소 수단             | 정산 계산기, 참여자 응답 수정 |
| **F011** | 입금 여부 수동 체크   | 주최자가 참여자별 입금 완료 여부를 직접 체크                      | 정산 마감 확인을 위한 최소 필수 기능                      | 정산 계산기                   |
| **F012** | 내 분담액 확인        | 참여자가 본인 응답 수정 페이지에서 본인의 정산 금액 확인          | 참여자 입장에서 정산 결과를 알아야 송금 가능              | 참여자 응답 수정              |

### 2. MVP 필수 지원 기능

| ID       | 기능명                        | 설명                                                                     | MVP 필수 이유                            | 관련 페이지                    |
| -------- | ----------------------------- | ------------------------------------------------------------------------ | ---------------------------------------- | ------------------------------ |
| **F020** | 기본 인증                     | 이메일/비밀번호 + 구글 OAuth 로그인/회원가입/로그아웃 (기존 구현 재사용) | 주최자 식별을 위한 최소 인증             | 로그인 페이지, 회원가입 페이지 |
| **F021** | access_token 기반 참여자 검증 | 참여자별 고유 토큰으로 본인 응답만 수정 가능하도록 서버에서 검증         | 계정 없는 참여자 구조의 보안적 최소 장치 | 참여자 응답 수정               |

### 3. MVP 이후 기능 (제외)

- 카풀 매칭/좌석 관리 로직 (현재는 자유텍스트 메모로만 처리)
- 실제 결제/송금 연동 (계좌번호 텍스트 공유만 지원)
- 참여자 계정/로그인 시스템
- 모임 반복/템플릿 생성
- 알림(이메일/푸시) 시스템
- 참여자 프로필, 아바타, 별도 회원 관리
- 모임 카테고리/태그/고급 검색
- 다중 정산(분할 결제, 항목별 정산 등)

## 📄 페이지별 상세 기능

### 내 모임 목록

> **구현 기능:** `F002` | **메뉴 위치:** 로그인 후 최초 진입 화면

| 항목            | 내용                                                                                                                            |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 주최자가 자신이 만든 모든 모임을 한눈에 파악하는 대시보드                                                                       |
| **진입 경로**   | 로그인 성공 후 자동 이동, 이후 모든 화면에서 상단 메뉴로 재진입 가능                                                            |
| **사용자 행동** | 모임 목록을 스크롤하며 확인, 특정 모임을 클릭해 상세로 이동, 새 모임 생성 버튼 클릭                                             |
| **주요 기능**   | • 내가 만든 모임 리스트 표시 (제목, 일시, 상태, 참여자 수 요약)<br>• 모임 클릭 시 모임 상세로 이동<br>• **새 모임 만들기** 버튼 |
| **다음 이동**   | 모임 클릭 → 모임 상세(주최자), 새 모임 만들기 → 모임 생성                                                                       |

---

### 모임 생성

> **구현 기능:** `F001` | **메뉴 위치:** 내 모임 목록 → 새 모임 만들기

| 항목            | 내용                                                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 새로운 모임을 등록하는 입력 전용 화면                                                                                                                |
| **진입 경로**   | 내 모임 목록에서 "새 모임 만들기" 버튼 클릭                                                                                                          |
| **사용자 행동** | 제목, 설명, 장소, 일시, RSVP 마감일을 입력하고 저장                                                                                                  |
| **주요 기능**   | • 제목/설명/장소 텍스트 입력<br>• 일시(starts_at) 선택<br>• RSVP 마감일(선택 입력)<br>• 입력값 유효성 확인(제목/일시 필수)<br>• **모임 만들기** 버튼 |
| **다음 이동**   | 저장 성공 → 모임 상세(주최자), 실패 → 에러 메시지 표시 후 현재 화면 유지                                                                             |

### 모임 상세 (주최자)

> **구현 기능:** `F003`, `F005`, `F008` | **인증:** 로그인 필수(본인 소유 모임만 접근)

| 항목            | 내용                                                                                                                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **역할**        | 특정 모임의 공지 정보와 참여자 현황을 관리하는 주최자의 메인 작업 화면                                                                                                                                 |
| **진입 경로**   | 내 모임 목록에서 모임 클릭, 모임 생성 완료 후 자동 이동, 모임 수정/정산 계산기에서 복귀                                                                                                                |
| **사용자 행동** | 모임 정보 확인, 참여자 공개 링크 복사, 참여자 현황 테이블 확인, 수정/정산 화면으로 이동                                                                                                                |
| **주요 기능**   | • 모임 제목/설명/장소/일시/마감일/상태 표시<br>• 참여자 공개 RSVP 링크 표시 및 **복사** 버튼<br>• 참여자 현황 테이블(이름/참석여부/카풀 메모)<br>• **모임 수정** 버튼<br>• **정산 계산기로 이동** 버튼 |
| **다음 이동**   | 모임 수정 클릭 → 모임 수정, 정산 클릭 → 정산 계산기                                                                                                                                                    |

### 모임 수정

> **구현 기능:** `F004` | **인증:** 로그인 필수(본인 소유 모임만 접근)

| 항목            | 내용                                                                                                           |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| **역할**        | 기존 모임 정보를 갱신하는 편집 전용 화면                                                                       |
| **진입 경로**   | 모임 상세(주최자)에서 "모임 수정" 버튼 클릭                                                                    |
| **사용자 행동** | 제목/설명/장소/일시/마감일/상태(open/closed/cancelled)를 수정하고 저장                                         |
| **주요 기능**   | • 기존 값이 채워진 입력 폼<br>• 상태(status) 변경(진행중/마감/취소)<br>• 입력값 유효성 확인<br>• **저장** 버튼 |
| **다음 이동**   | 저장 성공 → 모임 상세(주최자)로 복귀, 실패 → 에러 메시지 표시                                                  |

---

### 정산 계산기

> **구현 기능:** `F009`, `F010`, `F011` | **인증:** 로그인 필수(본인 소유 모임만 접근)

| 항목            | 내용                                                                                                                                                                                                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **역할**        | 모임 비용을 참여자 수만큼 N빵 계산하고 입금 여부를 관리하는 화면                                                                                                                                                                                                                           |
| **진입 경로**   | 모임 상세(주최자)에서 "정산 계산기로 이동" 버튼 클릭                                                                                                                                                                                                                                       |
| **사용자 행동** | 총금액 입력, 참여자별 정산 포함/제외 체크, 계좌 정보 입력, 참여자별 입금 여부 체크                                                                                                                                                                                                         |
| **주요 기능**   | • 총금액(total_amount) 입력<br>• 참여자별 정산 포함/제외 체크박스(is_excluded_from_settlement)<br>• 1인당 금액(amount_due) 자동 계산 및 표시<br>• 계좌번호/예금주/메모(bank_account/account_holder/memo) 입력<br>• 참여자별 입금 완료 여부(is_paid) 수동 체크<br>• **정산 저장/갱신** 버튼 |
| **다음 이동**   | 저장 성공 → 동일 화면에 계산 결과 반영, "모임 상세로 돌아가기" 클릭 → 모임 상세(주최자)                                                                                                                                                                                                    |

### 참여자 RSVP 랜딩

> **구현 기능:** `F006` | **인증:** 없음(공개 링크, 계정 불필요)

| 항목            | 내용                                                                                                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 참여자가 계정 없이 모임 참석 여부를 응답하는 진입 화면                                                                                                                             |
| **진입 경로**   | 주최자가 공유한 모임별 공개 링크로 직접 접속                                                                                                                                       |
| **사용자 행동** | 이름 입력, 참석/불참 선택, 카풀 메모(선택, 200자 제한) 입력 후 제출                                                                                                                |
| **주요 기능**   | • 모임 기본 정보(제목/일시/장소) 표시<br>• 이름(name) 입력<br>• 참석 여부(attending/not_attending) 선택<br>• 카풀용 자유텍스트 메모(note, 최대 200자) 입력<br>• **응답 제출** 버튼 |
| **다음 이동**   | 제출 성공 → 개인 응답 수정 링크(access_token) 안내 화면으로 전환, 실패 → 에러 메시지 표시                                                                                          |

### 참여자 응답 수정

> **구현 기능:** `F007`, `F012`, `F021` | **인증:** access_token 기반(계정 불필요)

| 항목            | 내용                                                                                                                                                                                                                  |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 참여자가 본인의 RSVP 응답을 재확인하고 수정하며, 정산 등록 시 본인 분담액을 확인하는 화면                                                                                                                             |
| **진입 경로**   | RSVP 제출 완료 후 안내된 개인 링크(access_token 포함)로 접속, 이후 동일 링크 재방문                                                                                                                                   |
| **사용자 행동** | 참석 여부/카풀 메모 수정, 정산이 등록된 경우 본인 분담액과 계좌 정보 확인                                                                                                                                             |
| **주요 기능**   | • access_token으로 본인 참여자 레코드만 조회(서버에서 토큰 일치 검증)<br>• 참석 여부/카풀 메모 수정<br>• 정산 등록 시 본인 1인당 금액(amount_due) 표시<br>• 계좌번호/예금주/메모 표시(안내용)<br>• **응답 저장** 버튼 |
| **다음 이동**   | 저장 성공 → 동일 화면에 갱신된 정보 표시, 실패(토큰 불일치 등) → 접근 불가 에러 표시                                                                                                                                  |

### RLS 정책 개요

- **events**: 주최자만 CRUD 가능(`auth.uid() = host_id`), 누구나 SELECT 가능
- **participants**: 누구나 INSERT/SELECT 가능, UPDATE는 클라이언트 직접 접근을 허용하지 않고 Server Action이 `access_token` 일치를 강제하는 절충 모델
- **settlements / settlement_shares**: 주최자만 편집(CRUD) 가능, 누구나 SELECT 가능

## 🛣️ 라우트 구조

```
app/protected/events/            — 주최자 전용 (기존 인증 보호 레이아웃 상속)
  page.tsx                       내 모임 목록
  new/page.tsx                   모임 생성
  [eventId]/page.tsx             모임 상세(공지, 참여자 테이블, 공개 링크)
  [eventId]/edit/page.tsx        모임 수정
  [eventId]/settlement/page.tsx  정산 계산기

app/e/[eventId]/                 — 참여자 공개 라우트 (비로그인 접근 허용)
  page.tsx                       RSVP 랜딩 (이름+참석여부+메모 입력)
  r/[accessToken]/page.tsx       개인 응답 수정 + 내 분담액 확인
```

- `proxy.ts`(기존 미들웨어 역할)에 `/e/` 경로를 인증 예외로 추가해야 참여자가 비로그인 상태로 접근 가능하다.
- 비회원이 DB를 직접 조작하는 RSVP 제출/수정, 정산 계산은 모두 Server Action으로 처리하여 `access_token` 검증을 서버 측에 가둔다.

## ✅ 정합성 검증 결과

- 기능 명세(F001~F012, F020, F021)의 모든 항목이 페이지별 상세 기능에 매핑되어 있음을 확인함
- 메뉴 구조의 모든 항목(내 모임 목록, 새 모임 만들기, 모임 상세/공지, 모임 수정, 정산 계산기, 로그인, 회원가입, RSVP 랜딩, 내 응답 수정)이 페이지별 상세 기능에 해당 페이지로 존재함을 확인함
- 페이지별 상세 기능에 기재된 모든 구현 기능 ID가 기능 명세에 정의되어 있음을 확인함
- 고아 항목(한쪽에만 존재하는 기능/페이지) 없음을 확인함
